# Борлуулалтын самбар — демо

Зохиомол демо өгөгдөлтэй статик хуудас (бодит бизнесийн тоо биш). Telegram Mini App туршилтад зориулсан.

- `/` — анхны борлуулалтын самбарын демо.
- `/store-report/` — «Дэлгүүрийн цонх»: нэг дэлгүүрийн тайлан (`?store=ST-13204`), код оруулах `?view=lookup`. Эх код `ui/store-report`; энэ хавтсыг `node scripts/package_store_report.mjs`-ээр үүсгэнэ, гараар засахгүй. `version.json` нь build болон файлын hash.
